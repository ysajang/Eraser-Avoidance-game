# Eraser Avoidance

A Flappy Bird-style game built with Phaser 3.

## Features

- Classic Flappy Bird gameplay
- Coin collection system
- Extra Life system (earned every 100 points)
- Dynamic difficulty adjustment
- Multiple background images
- Smooth coin path following

## How to Play

- Click or press spacebar to make the bird flap
- Avoid pipes and collect coins
- Earn Extra Lives at every 100 points
- Try to achieve the highest score!

## Technologies

- Phaser 3
- HTML5
- JavaScript

## Setup

1. Clone the repository
2. Open `index.html` in a web browser
3. Or use a local server:

   ```bash
   python -m http.server 8000
   ```

4. Navigate to `http://localhost:8000`

## Game Controls

- **Click** or **Spacebar**: Make the bird flap upward
- **Pause Icon**: Pause/Resume the game

## Game Features

- **Coins**: Collect coins to earn extra points
- **Extra Life**: Earn an extra life every 100 points
- **Dynamic Difficulty**: Game speed increases as your score increases
- **Background Changes**: Background changes every 50 points

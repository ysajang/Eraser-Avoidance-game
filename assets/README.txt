Assets Folder
=============

이 폴더에 다음 이미지 및 사운드 파일을 추가하세요:

이미지 파일 (선택사항 - 없으면 도형으로 표시됨):
- bird.png: 새 이미지 (권장 크기: 34x24 픽셀)
- pipe.png: 파이프 이미지 (권장 크기: 52x400 픽셀)
- background.png: 배경 이미지 (권장 크기: 400x600 픽셀)

사운드 파일 (선택사항):
- flap.mp3: 날개짓 소리
- score.mp3: 점수 획득 소리
- hit.mp3: 충돌 소리

무료 에셋 다운로드 위치:
- itch.io: https://itch.io/game-assets/free (검색: flappy bird)
- OpenGameArt: https://opengameart.org/
- Kenney.nl: https://kenney.nl/assets (추천!)
- Freesound.org: 효과음
- Zapsplat: 게임 사운드

픽셀아트 제작 도구:
- Piskel: https://www.piskelapp.com/ (무료 온라인)

주의: 파일이 없어도 게임은 정상적으로 작동합니다 (도형과 색상으로 표시됨).
